This repository hosts up-to-date versions of the system firmware for the Nintendo Switch. Whenever a new firmware update is released, it will be automatically downloaded and uploaded to the [releases](https://github.com/preservia/firmware/releases) page. You can always download the latest firmware version by tapping the download button below. For additional information, please view the sectios below.

## Additional Info

### Firmware Hashes
To view and verify individual file hashes for each firmware version, please view [`hashes.md`](./hashes.md). More info on this will come shortly.

### URLs
You can use these URLs to easily fetch important info

- Download latest firmware:
```
https://preservia.github.io/firmware
```

- View info about the latest firmware version:
```
https://preservia.github.io/firmware/info/latest.json
```

- View info about a specific version:
```
https://preservia.github.io/firmware/info/[version].json
```
